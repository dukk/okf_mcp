# M16 Task 2: `shared::ephemeral`, short-lived state in memory or Redis (issue #555)

The building block Tasks 5 and 7-10 move their in-memory maps onto: one type
that is today's `ExpiringMap` without `[redis]`, and Redis keys with Redis
TTLs with it (spec Decisions 3-8).

## Added

- `src/shared/ephemeral.rs`:
  - `Ephemeral<V>` (`Memory(ExpiringMap<V>)` or `Redis { .. }`) with `new`,
    `insert`, `take`, `update`, `remove`, `remove_stale` and a test-only
    `len` (memory only).
  - `take` is `GETDEL`, so an entry is taken once across replicas.
  - `update` reads the value, runs the change on a decoded copy, and writes it
    back with a Lua compare-and-set that writes only if the stored bytes are
    unchanged and keeps the remaining `PTTL`. It tries 8 times, then answers
    `Busy` (counted as `update`). The closure may run more than once.
  - Values are the JSON envelope `{"v": <version>, "d": <value>}`. Another
    version, another shape or bytes that are not JSON read as absent and are
    counted as `decode`.
  - Every key the Redis arm writes is `Redis::key(space, hashed(key))`, so no
    presented id appears in a key name.
  - `Index` (per-actor pointers) with `replace`: in memory today's
    `update_or_insert_sliding`, in Redis `SET <actor key> h(entry) PX <ttl> GET`,
    one atomic swap that returns the old pointer as an opaque `Stale` (its
    `Debug` prints `Stale(<redacted>)`).
  - `Keyspace` and `IndexSpace` with their key-name parts and versions.
- Tests: every Redis body runs on a standalone Redis and a one-node Valkey
  cluster (`in_both_modes!`), memory alongside where it applies: single-use
  take, racing takes on two handles, 16 concurrent updates over two handles,
  the fixed lifetime and expiry, version and shape mismatches counted as
  `decode`, no presented id in key names or index values, the index swap and
  its sliding TTL, a Redis outage answering `Busy`, a forced lost race that
  reruns the closure on a fresh copy, and an always-losing update that is
  `Busy` after 8 attempts.
- `tools/agentic/lessons.md`: the rule that an `Ephemeral::update` closure may
  run more than once.

## Changed

- `src/shared/mod.rs`: `pub mod ephemeral;`; the test helper `error_count`
  moved into `shared::testing` so both modules' tests use it.
- `src/oauth/expiring.rs`: module docs say it is also `Ephemeral`'s and
  `Index`'s memory variant. Its code is unchanged.
