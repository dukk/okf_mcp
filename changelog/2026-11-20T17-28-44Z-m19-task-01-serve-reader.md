# M19 Task 01: embed and serve the reader's files

## Added
- `src/http/read.rs`: the mobile reader's routes `/read`, `/read/`,
  `/read/shell.json` (every precached file with its SHA-256), `/read/sw.js`
  (shell version substituted; 404 until the worker lands) and
  `/read/{*path}`, with the console's security headers.
- `src/http/read/`: `index.html`, `manifest.webmanifest` and four PNG icons.
- `build.rs` embeds `src/http/read` as `READ_ASSETS` through the same
  function as the console's `ASSETS`.
- `ui::console_file()` and the `png` and `webmanifest` content types.

## Changed
- `ui::asset()` takes the embedded table to serve from, so the console and the
  reader share one code path.
- `build.rs` generates both tables through one `embed` function.

## Notes
- The shell version hashes every precached file, the shared console files
  (`pico.min.css`, `dom.js`, `format.js`) included, so a change to any of them
  updates installed apps.
- The worker, stylesheet and scripts arrive in later M19 tasks, so the shell
  listing names only the files that exist today.
- The plan's Task 1 line references for `src/http/mod.rs` (`:18`, `:413`) were stale, and are corrected in the plan under a dated `Corrected (issue #808)` note (`ui::routes()` is near line 433; rustfmt sorts `mod read;` into the module list).
