## Added
- `whoami` MCP tool (issue #666): read-only, no arguments. It returns the calling credential's `user` and `user_label` (null for an unassigned key), `actor` and `actor_label`, `credential` (`api_key` or `oauth`) with the OAuth `client_name`, `access`, its reach (`all_catalogs`, or `catalogs` with each level), `default_catalog`, and `now` from the injected clock in the stamps' format. The server instructions and `docs/reference/tools.md` mention it.

## Changed
- The tool count in the annotation and reference tests goes from 43 to 44, and in the investigator client and maintenance tests from 42 to 43.

## Notes
- It shows the credential's own kind, access, reach and default catalog, plus the user and their label, and no key id, key name, token or grant id (`list_changesets` shows the key id and name; `whoami` does not). A console session is refused with `Forbidden`, as `send_feedback` does.
- It does not change what `by` defaults to; it lets an agent say who it acts for.
