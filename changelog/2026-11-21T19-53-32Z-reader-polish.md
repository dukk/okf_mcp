# Mobile reader polish

The reader at `/read/` gets a Notion-like design and six fixes found on a
phone. Design: `docs/superpowers/specs/2026-11-21-reader-polish-design.md`;
plan: `docs/superpowers/plans/2026-11-21-reader-polish.md`. The per-task
entries (`changelog/2026-11-21*-reader-polish-*.md`) keep the detail; the
reference is `docs/reference/reader.md`.

## Added
- Server: titles and descriptions on recent changes, descriptions on the
  tree, `snippet_text` on search hits; fonts from the server's own origin
  in the CSP.
- Self-hosted Inter and Literata (Latin subsets, OFL), an icon sprite, and
  design tokens for light, dark and a theme choice on Account (System,
  Light, Dark).
- Header with the catalog's label and mark, tab icons, and shared screen
  parts.
- Home: page count in the search box, Jump back in, an activity timeline
  with filters, day headings, batched groups and Show older.
- Folder: About, described folders with counts, described concepts, a Log
  row. Concept: meta row, lede, On this page, serif body, one backlink row
  per document. Search: plain snippets and Show more.
- `tools/agentic/gate.sh worker` for the reader's Node tests.
- `serve_a_sample_catalog_for_the_visual_check`, an ignored test that serves
  a placeholder catalog for the visual check on a phone.

## Fixed
- Screens kept the previous screen's scroll position.
- Backlinks repeated a document once per link.
- A concept of level-1 sections had an empty outline.
- The system navigation bar was green.
- Search showed raw markdown and stopped silently at 50.
- Long concepts stopped behind "Show the whole concept".
- From the visual check on a phone: the concept body was drawn as a Pico
  card, the breadcrumbs and the "On this page" list carried Pico's `nav` and
  `details` spacing, the Home search box had an extra margin, and a wrapped
  meta row could start with a separator.

## Changed from the plan
Every dated correction note in the plan, in one line each.
- #860 review (server fields): `snippet_text` is built from the source with
  the renderer's parser, not cut from `snippet`; and a block is found by
  its range overlapping the matched line, since it may start after a prefix
  (`> `, a list marker, a table row's `|`).
- #860 review (concept): the history read for "Edited by" is optional: the
  concept draws without it, and the line fills in later.
- #864: the font script reads Literata's own release layout
  (`fonts/variable/Literata[opsz,wght].ttf`), not a Google Fonts file name;
  the outputs are about 98 KB in all.
- #866: two existing journeys changed: the picker journey sets the catalog's
  label and waits for it as the breadcrumb root (not "Contents"), and the
  interim search snippet uses `hint`, because the `.meta` flex row made the
  hit unclickable at its centre.
- #867: "Jump back in" says "Synced N ago", not "read N ago"; and "Show
  older" removes its "needs a connection" notice once a later read works,
  with journeys for its failure paths.
- #868: the picker journey asserts the label "Main" and needs no
  `UNTITLED_CATALOG` import.
- #869: three journeys added to the concept's Step 1 (offline: no edit line;
  a lost grant answered to the history read evicts; the offline journeys
  wait for the worker to cache before going offline).
- #870: a successful "Show more" after an offline attempt removes its
  notice, with three more journeys.
- #872: the sample catalog's Kubernetes description is quoted (an unquoted
  colon made the front matter invalid YAML), plus the adb, mockup-serving
  and tab observations in Task 10.

## Follow-ups
Nothing here is filed as an issue.
- A true reading time for Jump back in: "read 2 h ago" needs a reading time
  stored per copy, because `X-Read-Cached-At` is the last network read and
  an offline read keeps it.
- Considered at the visual check and left as they are, by the owner's
  decision:
  - the Home "Activity" heading, which the mockup does not have;
  - the 44px header icon button (the mockup's is 36px), which starts the
    page about 24px lower;
  - type and tag pills in the concept's meta row, where the mockup has one
    line of text;
  - no icon on the callout quote (the rendered markup carries none);
  - the system monospace font for code, where the mockup uses a font that
    is not self-hosted;
  - actor names shown as stored (lowercase), where the mockup shows display
    names;
  - the dark "Sign out" button, white on the accent, at about 3:1 contrast;
  - the Android navigation bar colour, which cannot be judged in a browser
    tab (the `theme-color` metas are `#ffffff` and `#191919`).
- Known flakes seen under load in the gates, not caused by this milestone:
  the console's `account::` journeys (a Chromium port clash, a detached
  click).
