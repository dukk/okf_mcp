# Release v0.25.0 (2026-11-20T18:26:52Z)

## Upgrade notes

- **Two migrations, 0029 and 0030,** let the `feedback` table's
  `credential_kind` check accept `session`. 0029 adds the wider check as
  `NOT VALID`, so its ACCESS EXCLUSIVE lock is brief. 0030 validates the check
  under a SHARE UPDATE EXCLUSIVE lock, so feedback can still be read and
  written while it runs. Both run automatically at startup.
- **New optional branding settings, `docs_url` and `onboarding_url`.** Both
  default to `none`, so nothing changes until you set them (an `[auth]`
  default, or an override on the Settings page or through `okf-mcp settings`).

## New

- **`whoami` tool** (#783, issue #666). Returns the caller's user, actor,
  credential kind (API key or OAuth, with the client name), catalog access,
  default catalog, and the server's clock. It takes no arguments.
- **`cited_by` tool** (#822, issue #761). Finds every concept that cites a
  source, matched by `source_id` and/or `resource`, across the connection's
  catalogs, and includes drafts when a `changeset` is passed.
- **Folder descriptions without a free edit of the parent index** (#789,
  issue #668). `create_concept` accepts `folder_summary`, and `index` works on
  a folder. Two sessions that each create a top-level folder no longer
  conflict on `/index.md`.
- **Onboarding, help and feedback in the web console** (#797, issue #793).
  After a successful first password setup, users are redirected to the
  `onboarding_url` guide. The sidebar has a Documentation link (`docs_url`).
  With `[feedback]` configured, a Send feedback form goes through the same
  checks, rate limit and queue as the `send_feedback` tool.

## Fixed

- **`pending_changes` shows a stale replayable entry the way publish writes
  it** (#791, issue #787). Before, a stale `log` or `index` entry showed every
  line published since as deleted, although publish keeps those lines.
- **`revert` of a path already in the changeset bases the entry on the
  revision published now** (#794, issue #788). Before, it kept the old base,
  so reverting to catch up a stale entry produced an entry that could never
  publish.

## Docs and process

- Design spec and implementation plan for the mobile reader PWA at `/read/`
  (#796). Docs only, no code yet.
- An agentic lessons rule against bare stdin readers in background commands
  (#779).
