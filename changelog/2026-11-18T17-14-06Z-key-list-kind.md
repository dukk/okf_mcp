# key list marks OAuth grants

## Added
- `okf-mcp key list` rows end with `kind key|oauth` and `client <name>` (`client -` for a static key), so an OAuth grant can be told from a key that shares its name and actor.

## Changed
- `okf-mcp oauth grant list` uses the same row, so its trailing columns are now `user U`, `kind oauth`, `client <name>` (the client cell is unchanged; `kind oauth` is new before it).
- The column-order test covers both kinds. `docs/operations.md` describes the new columns.

## Notes
- The change is additive: the new cells are at the end of the row. `key list` has no JSON mode, so nothing else needed to change.
