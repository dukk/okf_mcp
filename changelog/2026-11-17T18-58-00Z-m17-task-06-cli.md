# M17 Task 6: CLI display names

## Added
- `okf-mcp user update NAME --display-name TEXT` and `okf-mcp team update NAME --display-name TEXT`: parse with `DisplayName::parse`, call `users::set_display_name` / `teams::set_display_name` as `AuditActor::cli()` with `owner: None`, and print `updated user|team NAME display name: "old" -> "new"`. The old value is read with `find` just before the write (the store functions return nothing), so under a concurrent rename the printed old value can be stale; the write itself is unaffected.
- `okf-mcp catalog create --display-name TEXT` (default empty).
- `catalog update` takes `--display-name` and/or `--description` (an `ArgGroup` with `required` and `multiple`), and prints one line per flag given via `describe_details_change`.
- Tests: `user_and_team_update_change_the_display_name` (output, a personal team refused with the store's text, an unknown user, an 81-character name), `catalog_create_and_update_store_the_display_name`, `catalog_update_prints_one_line_per_field_given`, and the parse test for the arg group.

## Changed
- `CatalogCommand::Update.description` is now `Option<String>`.
- `docs/operations.md` and `README.md` list the new commands and flags.
