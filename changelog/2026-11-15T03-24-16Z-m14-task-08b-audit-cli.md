# M14 Task 8b: `okf-mcp audit list` and `audit export` (issue #403)

## Added

- `okf-mcp audit list`: audit entries, newest first, one tab-separated
  line each (id, time, action, actor, target, teams, details as JSON).
  The actor is `person NAME`, else `credential ID`, else the actor label;
  the target is `user NAME`, or `KIND NAME` followed by `person NAME` when
  the entry names one. Control characters in names and labels are escaped,
  so a stored tab or newline cannot shift a column or forge a line.
- `okf-mcp audit export`: every matching entry as JSON Lines on stdout,
  the records `GET /api/v1/audit/export` answers.
- Both take the REST filters as flags (`--team`, `--action`, `--actor`,
  `--target`, `--since`, `--until`, `--after`, `--limit`), parsed by
  `store::audit::parse_filters`, and read as `Viewer::Admin`: the CLI has
  operator access.
- `store::audit::export_lines`: the paged export (500 entries a page, the
  cursor moved to each full page's last id), shared by the route and the
  CLI.
- Parity rows for both commands in `docs/operations.md`, and `audit` in
  `tests/admin_parity.rs`' scanned groups; the CLI usage in the Audit API
  section.

## Changed

- `GET /api/v1/audit/export` builds its body with `audit::export_lines`
  instead of its own loop (same output).
- `comma_list` moved from `src/cli/people.rs` to `src/cli.rs`, beside
  `tab_row` and `labelled`.
