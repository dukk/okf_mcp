# M17 Task 1: the label rule and `DisplayName`

## Added
- `src/labels/mod.rs`: the `DisplayName` newtype (trimmed, at most 80 characters, no control characters or U+2028/U+2029; a 422 `LimitExceeded` with `limit: "display_name"` otherwise).
- `user_label`, `team_label` and `catalog_label`, pure functions that never return a slug or an empty string, and `export_stem` for a header-safe ASCII filename stem.
- Unit tests and three `hegel` property tests (labels are never empty; a parsed name re-parses to itself; an export stem is at most 40 ASCII bytes with no leading or trailing hyphen), with boundary cases for the 40-byte cap and a check that a refusal carries `limit: "display_name"`.

## Changed
- `src/lib.rs` declares `pub mod labels;`.
- The M17 plan's `catalog_label` code is corrected: the plan's tail expression borrowed a local across the end of the block and did not compile.
